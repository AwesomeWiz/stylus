# Brand asset provenance

The Stylus brand source at `brand/stylus-logo-source.png` was generated for the
project on 2026-09-05. Its embedded C2PA manifest identifies OpenAI Media
Service, `gpt-image` 2.0, and trained-algorithmic media. The optimized runtime
mark at `apps/web/public/brand/stylus-mark.png` was derived from that source and
introduced in the same repository commit (`043b12d`).

No third-party logo, stock image, proprietary font, or Figma export is included
in the current asset directory. See `TRADEMARKS.md` for use of the Stylus name
and branding.

Future assets must record their creator or source, applicable license or
permission, material modifications, and redistribution terms before they are
committed. Screenshots must use fictional demo data and follow
`docs/OPEN_SOURCE_RELEASE.md`.
