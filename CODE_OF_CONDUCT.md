# Community conduct

Be respectful, specific and constructive. Welcome people with different
backgrounds and levels of experience. Review ideas and code without personal
attacks. Harassment, discrimination, threats, doxxing and unwanted sexual attention
are not acceptable in project discussions, contributions or community events.

Maintainers may edit or remove harmful content, close a discussion, or restrict
participation. They should explain decisions privately when appropriate and
apply these standards consistently, including to maintainers.

To report a concern, request a private contact channel from the maintainer through
the repository without posting personal details or allegations publicly. Security
issues follow [SECURITY.md](SECURITY.md). A private reporting channel must be
confirmed before sensitive information is shared. The project does not promise
continuous monitoring or a fixed response time.
