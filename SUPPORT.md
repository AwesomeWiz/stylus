# Getting help

For installation and configuration, start with [self-hosting](docs/SELF_HOSTING.md)
and its troubleshooting section. Search existing
[issues](https://github.com/AwesomeWiz/stylus/issues) before opening a report.

Include your Stylus commit/version, operating system, Node version, expected and
actual behavior, and a minimal fictional reproduction. Redact environment values,
cookies, OAuth responses, provider identifiers and private tenant content.

Use the bug template for defects and the feature template to discuss a bounded
proposal. Please do not use public issues to request account recovery from an
independently hosted deployment; contact that deployment's operator. Stylus is an
early beta with community support and no support SLA.

For suspected vulnerabilities, use [responsible disclosure](SECURITY.md) instead
of posting exploit details publicly.
