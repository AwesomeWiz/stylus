# 0.1.0-beta.1 — first public beta candidate

Stylus connects evidence to execution for early-stage teams. This is the first
proposed public version: existing packages were 0.1.0 and no prior tags exist, so
0.1.0-beta.1 conveys the actual pre-release history without implying a 1.0 promise.
No tag or release has been published by the hardening task.

## What teams can evaluate

- Daily attention, Tasks with prerequisites, minimal Milestones and working Notes.
- Collaborative Boards with Sections, images, native entity cards, voting and
  local Section presentation.
- Marketing Evidence → Hypothesis → Experiment → execution → reviewed Learning,
  with explicit Company Memory promotion and exact provenance.
- Bounded Creative Studio, Strategic Review and advisory Ask Council workflows,
  retaining versioned outputs and independent execution limits.
- Optional GitHub/Drive/Calendar references and explicit Calendar creation;
  provider credentials are encrypted server-side and connections are role-scoped.
- Self-hostable Core with optional AI/providers and an outbound heavy-compute worker.

Release preparation adds AGPL-3.0-only licensing, third-party/font provenance,
public self-host/contribution/security documentation, reproducible CI, optional
fictional data, accessible public error recovery and narrower Task read transport.
Task rendering progressively reveals list rows without dropping matching data;
Core panel reads no longer wait in a provider's Server Action queue.

## Beta limits

Read [the audit](RELEASE_AUDIT.md) for measured performance and exact verification.
Remote CI and the complete Docker-dependent local authenticated clean-install
gate must not be treated as passed before execution. Physical-device/engine and
screen-reader coverage are recorded separately, not called WCAG certification.

Integrations, AI and worker capabilities are optional. Drive's restricted scope
may require Google's public-deployment verification. No automatic Calendar sync,
Drive ingestion, GitHub business writes, new startup modules or generic automation
are included. Image drag-sizing and other explicitly deferred product refinements
remain outside this release-hardening scope. Public hosted operators must supply
their own deployment-specific terms/privacy notice and manage provider approvals.
